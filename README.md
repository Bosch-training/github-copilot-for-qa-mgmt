# GitHub Copilot for QA Management

A one-day workshop teaching Test Managers and Group Managers to use GitHub Copilot, Jira MCP, and n8n for AI-assisted project and test management — status reporting, risk review, live Jira analysis, automated reporting, PR scope checks, and coverage-gap checks.

## Structure

- `course-outline/` — the approved course outline (source of truth)
- `presentation/` — slide deck (owned separately)
- `lab/` — everything needed to run the workshop: pre-work, module lab guides, sample data, facilitator notes. Start with `lab/README.md`.
